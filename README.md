# PeopleFlow HRMS

A polished, responsive human resource management dashboard built with React and TypeScript.

## Features

- Workforce overview with attendance trends and key metrics
- Searchable employee directory with an add-employee workflow
- Live attendance status and personal check-in/check-out
- Leave balances and approve/decline request workflows
- Responsive desktop and mobile navigation

## Development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm test
npm run lint
npm run build
```
